# **App Name**: Digital Ghost

## Core Features:

- Neural Reflection Log: An immersive journal for recording daily memories, thoughts, and reflections in a minimal glassmorphic interface.
- Resonance AI Tool: A conversation tool that leverages the OpenAI API and your memory vault to simulate chats with your older, wiser, or alternate selves.
- Chronicle Timeline: A cinematic scrolling timeline that highlights past entries and surfaces 'On This Day' memories using interactive cards.
- Vocal Echo Archive: Direct upload and storage for voice notes, featuring real-time visualization of your voice frequency.
- Oneirology Vault: A dedicated dream tracker that utilizes the memory database as a tool to interpret recurring themes and subconscious patterns.
- Identity Evolution Map: Dynamic, animated charts showing your personality shifts, mood trends, and emotional growth over time.
- Neural Vector Search: Advanced contextual retrieval that allows you to search through your entire life story via conceptual relevance.

## Style Guidelines:

- Primary Color: Luminous Lavender (#A38CF4), an ethereal violet hue that suggests a ghostly digital presence.
- Background Color: Obsidian Void (#111016), a heavily desaturated deep violet to create a cinematic dark mode.
- Accent Color: Atmospheric Blue (#5F8CFA), used for high-contrast highlights and interactive elements to create a cold, futuristic glow.
- 'Space Grotesk' is used for cinematic headlines to provide a high-tech, futuristic feel, paired with 'Inter' for clear, emotional body text.
- A minimalist, responsive grid utilizing glassmorphism and background blur effects for an layered, immersive feel.
- Fluid, physics-based transitions via Framer Motion with floating particles and soft-glowing pulsing gradients during AI interactions.
- Thin-stroke, monochromatic icons that emphasize a sense of airy weightlessness and technological sophistication.
